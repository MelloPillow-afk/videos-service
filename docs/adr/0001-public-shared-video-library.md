# Public viewing of one shared video library

Pilgrims has one shared video library. All administrators can manage every video, regardless of its creator; ready, published videos can be browsed and played anonymously. Per-owner and organization boundaries are outside this MVP.

Publication controls API discovery. Public CDN delivery is an accepted MVP trade-off: previously obtained media links may remain usable after unpublishing or deletion until cache expiry or cleanup. Authentication at the API alone is not intended to restrict media delivery.

Accepted during the design interview on 2026-10-16.
